# 资源与许可证

[返回首页](../README.md) · [构建与安装](build.md)

项目代码许可证见根目录 [GNU GPL v3](../LICENSE)。第三方代码、纹理、模型、字体和数据适用各自的授权条款。

## 依赖

CMake 下载固定源码依赖时，将可用的上游许可说明安装到 `<prefix>/share/licenses/npgs/`。系统库与系统字体的许可和分发信息由相应软件包提供。

## 资产

发布资源包前，维护者应记录每项资产的来源、许可、署名要求与再分发条件：

| 资源类别 | 打包要求 |
| --- | --- |
| 天空盒、图片盘、按钮及其他纹理 | 补齐来源与授权清单，保留要求的署名 |
| MIST 恒星参数等科研数据 | 核对数据发布条款与引用要求 |
| 第三方模型 | 按原作者授权选用 |
